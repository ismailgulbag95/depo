# UI Skills

Bu beceri, `ibelick/ui-skills` kütüphanesinin projede kullanılmasını temsil eder.

## Kullanım
Bu kütüphane terminal üzerinden şu komutlarla çalışır:
- `npx ui-skills categories` (Kategorileri listeler)
- `npx ui-skills list --category motion` (Animasyon bileşenlerini listeler)
- `npx ui-skills get [bileşen_adi]` (Bileşeni projeye kurar)

Yapay zeka (ben), bu beceri aktifken gerektiğinde size bu komutları çalıştırmanızı önerecektir.
